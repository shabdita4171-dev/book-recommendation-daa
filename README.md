# Graph-Based Book Recommendation System Using DAA Algorithms

A lightweight academic DAA project. Books are graph vertices, similarity relationships are weighted edges.

## Algorithms
BFS, DFS, Dijkstra, Merge Sort and Priority Queue.

## Run on Windows
Double-click `run.bat`.

Manual:
```text
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

Open http://localhost:8501 if needed.

No ML, APIs, database or internet services are required.
